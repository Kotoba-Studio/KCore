
# ⚙️ KCore

[![Minecraft Version](https://img.shields.io/badge/Minecraft-1.21%2B-brightgreen.svg)](https://papermc.io)
[![Platform](https://img.shields.io/badge/Platform-Paper%20%7C%20Folia%20%7C%20Canvas-blue.svg)](https://papermc.io)
[![Folia Support](https://img.shields.io/badge/Folia-Supported-success.svg)](https://papermc.io/software/folia)
[![Build](https://img.shields.io/badge/Build-R01--v9-8A5CF6.svg)](#)

**KCore** là gameplay core dành cho EcoSMP, tập hợp các hệ thống thiết yếu như Home, Warp, Spawn, TPA, RTP, Player Vault, Settings và Custom Menu vào một plugin duy nhất.

Được thiết kế tập trung vào hiệu năng, khả năng tùy biến và hỗ trợ tốt cho Paper/Folia hiện đại.

---

## ✨ Tính năng

- **Teleport System** — Home, Warp, Spawn, TPA và RTP.
- **Player Utilities** — Settings, Profile và Leaderboards.
- **Player Vault** — kho đồ cá nhân với cơ chế lưu trữ an toàn.
- **Custom Menu Engine** — xây dựng GUI hoàn toàn bằng YAML.
- **Rank Policies** — tích hợp LuckPerms cho giới hạn và quyền lợi theo rank.
- **Multi-Economy** — Vault, PlayerPoints, KShards và provider tương thích.
- **Protection Modules** — các module bảo vệ server tích hợp sẵn.
- **Modern Server Support** — Paper, Folia và Canvas.

## 📜 Lệnh chính

| Lệnh | Mô tả |
| :--- | :--- |
| `/home [name]` | Dịch chuyển tới Home |
| `/homes` | Mở giao diện Homes |
| `/warp [name]` | Dịch chuyển tới Warp |
| `/warps` | Mở danh sách Warp |
| `/spawn` | Trở về Spawn |
| `/tpa <player>` | Gửi yêu cầu dịch chuyển |
| `/rtp` | Random Teleport |
| `/settings` | Mở cài đặt người chơi |
| `/profile` | Xem hồ sơ |
| `/pv` | Mở Player Vault |

> Danh sách command, permission và admin command đầy đủ có trong Documentation.

## 🔗 Tích hợp

KCore hỗ trợ tùy chọn:

- **LuckPerms**
- **Vault / VaultUnlocked**
- **PlaceholderAPI**
- **PlayerPoints**
- **KShards**

Các integration chỉ được kích hoạt khi provider tương ứng tồn tại trên server.

---

## 📥 Cài đặt

1. Tải phiên bản KCore mới nhất.
2. Thả file `.jar` vào thư mục `plugins/`.
3. Khởi động server để KCore tạo cấu hình mặc định.
4. Chỉnh cấu hình theo nhu cầu và restart server.
